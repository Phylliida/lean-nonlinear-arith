## Traps / lessons (F3/F4 sessions — also in BOARD)

- **`Meta.evalExpr` of a bare FUNCTION const mis-evaluates on this
  toolchain** (v4.25.0 Nix): `TraceBundle.isV0` came back `false`
  where `#eval` gives `true`; full APPLICATION exprs evaluate
  correctly. Fix shape: all native checks in one compiled function
  (`Walk.precheck`), consumed via a single application evalExpr. Root
  cause open.
- **`mkApp` applies args to leading IMPLICIT binders too** — use
  `mkAppM` for heads with implicit prefixes.
- **`Classical.byContradiction : (¬p → False) → p`** in 4.25 core (not
  `(¬p → p) → p`).
- **`List.mem_cons` binder order is `{α} {b} {l} {a}`** (element LAST).
  Probe `#check @…` before any `mkAppOptM`.
- **`lemma` is a RESERVED WORD in 4.25** — `TraceBundle` literals must
  use the anonymous `⟨steps, lemma⟩` form.
